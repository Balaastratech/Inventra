## Shared fixtures / infrastructure (not tests themselves)

### `submission/tests/conftest.py`
- **`_no_real_email_by_default`** (autouse fixture, line 30) — Forces `config.email_enabled=False` and `config.vendor_email_enabled=False` for every test via monkeypatch on `nodes`, `email`, and `vendor_email` modules, regardless of what `submission/.env` has configured locally. Prevents any test from making a real Gmail SMTP call. Tests that want real email behavior override this within their own fixture (which runs after and wins for that test's duration).

### `submission/tests/seed_extra.py`
Additive-only DB fixture loader (never edits provided seed/database rows). Defines:
- `EXTRA_CASES` — 17 isolated (sku, warehouse_id) pairs (DEL-02 through DEL-21) each cloned from an existing SKU's product/vendor data onto a fresh warehouse, with inventory snapshot, 30 days of sales_daily, and a monthly_budgets row.
- `INSUFFICIENT_HISTORY_CASE` = ("AC-003", "DEL-09") — sparse sales fixture (2 sales rows, both within 7 days) for the <3-observation insufficient-data scenario.
- `TRENDING_CASE` = ("AC-001", "DEL-22", 40, 0) — genuinely time-varying demand (2/day recent 7 days vs 4/day older 23 days) so 7-day/30-day windows disagree for a real reason.
- `_populate_vendor_contact_emails` — fills NULL `vendors.contact_email` with a synthetic address, additive/idempotent.
- `seed_extra(db_path)` — orchestrates all of the above; idempotent (checks existence before inserting).

### `submission/tests/reset_db.py`
- **`reset_business_state()`** — Deletes the LangGraph checkpoint file and `submission/used_tokens.sqlite`, re-runs `database/seed.py`'s `init_db`+`seed_data` (provided seed, unedited), then re-applies `seed_extra()`. Used as a `scope="module", autouse=True` fixture across nearly every test module to guarantee idempotent, order-independent test runs (earlier bug: tests passed only once against a freshly seeded DB because purchase_requests rows and a budget mutation persisted across runs).

### `submission/tests/__init__.py`
Empty file.
